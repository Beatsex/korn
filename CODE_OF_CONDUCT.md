# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, no harassment, insults or discrimination.
Critique the code and the sound, not the person.

Report problems to the maintainer via a private message on GitHub (@Beatsex).
Maintainers may remove comments, issues or contributors that break these rules.
